# Security

Please do not place credentials, cookies, private keys, local state, task
identifiers, or private project paths in public issues or pull requests.

For a suspected security problem, use a private channel provided by the
maintainer and include only the minimum reproducible evidence. If no private
channel is available, open a general issue without sensitive details and ask
for a private follow-up. Do not upload secrets as attachments.

Security reports should explain the affected version, the local host scope,
the smallest reproduction, and the impact. Remove or rotate any credential
that may have been exposed before reporting it.

CO-OP Loop is a workflow protocol, not an operating-system permission
boundary. Treat task instructions, local files, credentials, and external
publishing actions as sensitive even when a local validation command passes.
